# プログラム開発の進め方

開始日: 2026-06-25

## 目的

AI と一緒にプログラムを進めるときの基本方針を、あとから見返せるようにまとめておく。

## 基本方針

- まず最初に、既存の良いアプリや GitHub の公開プロジェクトを調べる
- いきなりゼロから作らず、使えるものはうまく使う
- 候補があれば、無料で使えるか、ローカルで動くか、商用条件はどうかを確認する
- 土台になるアプリを入れてから、日本語化や使いやすい見た目の調整をする
- 最後は、できるだけワンクリックで起動できる形に近づける

## 優先する進め方

1. 調査
2. 候補の比較
3. 一番合うものの採用
4. 導入
5. 日本語化
6. 不要機能を減らして使いやすく調整
7. 起動を簡単にする

## 調査するときの見るポイント

- 無料で使えるか
- 制限がどこにあるか
- Windows で動くか
- Blender と相性がよいか
- 画像から 3D、点群、変換など目的に合っているか
- 日本語化しやすいか
- ローカルだけで使えるか
- 将来、ボタンひとつで起動できる形まで持っていけそうか

## UI を整える方針

- 英語 UI のまま我慢しない
- ボタン名はやさしい日本語にする
- 不要な項目はできるだけ隠す
- 初心者でも迷いにくい順番に並べる
- 「何を押せばいいか」がすぐわかるようにする

## Codex への依頼方針

- 新しい案件では、まず既存候補の調査から始める
- GitHub や既存サービスの候補を 2〜3 個に絞って提案する
- できるだけ、導入後に日本語化や簡単起動まで進める
- 必要なら、案件ごとに起動用のバッチファイルや案内メモも作る

## 今回の確認事項

- Hunyuan3D-2mv の導入と日本語化がうまくいった
- 既存アプリを活用する方針が、作りたいものに合っている
- 今後もこの方針を共通ルールとして使う

## 次に増やしたい内容

- よく使う GitHub 候補の一覧
- 無料で使いやすかったアプリの記録
- 商用利用時に注意が必要なライセンスのメモ
- ワンクリック起動の共通パターン
