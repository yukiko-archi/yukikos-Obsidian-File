# 業務委託 データ管理・運用マニュアル

Google Driveを用いたデータ納品・管理手順

作成者: 藤
更新日: 2026-06-17

## 0. 事前準備

- 弊社から共有する「作業者個別フォルダ」の招待メールを承諾します。
- 付与された権限でフォルダへアクセスできることを確認します。

## 1. 案件フォルダの作成

- 案件開始時、弊社から通知されるキーコード名でフォルダを作成します。
- フォルダ内には、以下の2つを新規作成します。
  - `01_資料`: 弊社からの提供資料（指示書・参考データ等）を格納します。
  - `00_Archive`: 更新済みの旧データを格納します。
- 作成した図面データ等は、原則としてキーコードフォルダの直下に保存します。
- `3D`、`2D` などのサブフォルダ分けは行いません。

## 2. ファイル名の命名ルール

- フォルダを分けず、ファイル名だけで「内容」と「状態」を判別します。
- 命名形式は次の通りです。
  - `[種別・ステータス]_キーコード_日付.拡張子`
- ステータスの使い分けは次の通りです。
  - 作業中: `[3D図面・作業中]`、`[2D図面・作業中]`
  - 完了: `[3D図面・完了]`、`[2D図面・完了]`
- ファイル名例:
  - `[3D図面・作業中]_p2600005_20260506.step`
  - `[3D図面・完了]_p2600005_20260510.step`

## 3. バージョン管理

- キーコードフォルダの直下には、常に最新版のみを置きます。
- 日付更新やステータス変更（作業中→完了）で不要になった旧ファイルは、速やかに `00_Archive` フォルダへ移動します。

## 4. 運用・報告フロー

- キーコードを受領します。
- キーコード名でフォルダを作成します。
- フォルダ作成後、Slackにて藤（@藤）へメンション報告します。
- 報告を受け、弊社側で社内プロジェクトフォルダへのショートカットを作成します。
- `01_資料` 内のデータを確認、または直接資料を受け取り、作業を開始します。
- すべての成果物を「完了」タグへ更新し、最終報告を行います。

## 5. 注意事項

- 一度作成したフォルダ名は変更しません。ショートカットがリンク切れするためです。
- NDA（秘密保持契約）に基づき、本業務で使用・発生したデータおよび資料は、すべて本フォルダ内に保存します。
- 取り扱う情報はすべて機密情報です。目的外利用、第三者への開示、無断での複製・持ち出しは禁止します。
- 本マニュアルは運用改善のため随時更新します。更新時は速やかに通達されるため、常に最新の指示に従います。
- キーコードが不明な場合や運用に迷う場合は、作業着手前に必ず担当者へ確認します。
