**ai**: 「第二の脳プロジェクト　ログ」を確認しました！Gitの基本操作、しっかり記録されていますね。

忘れてしまった時のために、**「普段使いの基本コマンド」**をまとめておきます。この3ステップさえ覚えておけば大丈夫です。

### 1. 基本の3ステップ（日常の作業）
Obsidianでノートを編集したり、ファイルを整理した後は、以下のコマンドを順番に実行するだけです。

```bash
# 1. 変更したファイルをGitの管理対象に追加する
git add .

# 2. 変更内容を記録する（" "の中は分かりやすいメモでOK）
git commit -m "ここに作業内容を書く"

# 3. GitHub（クラウド）にアップロードする
git push
```

---

### 2. もし「あれ、今の状態どうなってる？」と思ったら
作業の途中で「今、何が変更されたんだっけ？」と不安になったら、このコマンドを打ってみてください。

```bash
git status
```
- `working tree clean` と出れば、すべて保存・同期済みで安心な状態です。
- 赤い文字でファイル名が出てきたら、まだ `git add` していない変更があるという合図です。

---

### 3. 困った時のヒント
- **「git pushしたらエラーが出る」場合:**
  他のPCなどで作業した後にpushしようとすると、先に `git pull`（最新状態の取得）が必要になることがあります。その場合は `git pull` を先に実行してください。
- **「パスワードを聞かれる」場合:**
  GitHubの仕様変更で、最近はパスワードではなく「Personal Access Token」が必要になることがあります。もしエラーで止まってしまったら教えてくださいね。
